# raahi-travel-app
🌍 RAAHI — Explore, Connect Share!#
🧭 RAAHI — Travel Social App

**RAAHI** is a full-stack, production-ready travel social platform built for travelers to share stories, plan itineraries, and connect in real-time.

---

## ✨ Features

- 🔐 **Phone-less Authentication:** Email and Username based JWT authentication.
- 📸 **Travel Feed:** Share photos, tag locations, add captions, and like posts.
- 📌 **Saved Itinerary:** Pinterest-style 2-column grid layout for saving travel spots.
- 💬 **Real-time Chat:** WebSockets (Socket.io) powered live chat room for travelers.
- 🎨 **Responsive UI:** Dark-mode travel UI built with Tailwind CSS.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express.js, Socket.io
- **Database:** PostgreSQL (Supabase)
- **Deployment:** Vercel (Frontend), Render (Backend)
